# 站点标签碰撞处理伪代码

```text
输入：站点列表、设备方向表
输出：每个站点标签的位置与连接线

按站点坐标排序，保证每次计算结果稳定

for each 站点:
    设备 = 根据 station.deviceId 查询设备方向表
    标签 = 默认将设备编号以单行横向形式放在站点正上方（例如 C02）

    if 标签与已放置标签或站点图标重叠:
        yaw = 站点箭头朝向
        side = 设备.direction        // left 或 right，均为箭头局部方向

        if side == right:
            侧向向量 = (cos(yaw), sin(yaw))
        else:
            侧向向量 = (-cos(yaw), -sin(yaw))

        标签中心 = 站点坐标 + 侧向向量 × 安全间距

        while 标签仍重叠 and 未超过最大尝试距离:
            沿同一侧向向量再外移一档

    if 侧向移动后仍无法避让:
        标签向上逐档避让          // 极端数据兜底

    连接线起点 = 站点图标朝标签方向的边缘
    连接线终点 = 标签矩形距离站点最近的边缘点
    保存标签位置与连接线
```

说明：`direction` 表示相对站点箭头方向的左右，不是屏幕固定左右；标签矩形和文字始终保持正向，不跟随箭头旋转。
