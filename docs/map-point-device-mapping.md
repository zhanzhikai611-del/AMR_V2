# 地图点位与 CNC 映射说明

## 关系定义

地图点位表示 AMR 可以到达的物理服务位置，CNC 表示发出生产请求的设备。二者通过稳定标识建立资源映射：

`地图点位 pointUid / pointName → CNC deviceId → 服务动作`。

点位只保存 CNC 的关联关系与到达参数，不保存 CNC 的在线、加工或报警等实时状态。

## 推荐字段

```json
{
  "pointUid": "2824607688",
  "pointName": "D16",
  "deviceId": "CNC-01",
  "relationType": "SERVICE",
  "serviceActions": ["LOAD", "UNLOAD"],
  "approachYaw": 1.5707963705062866,
  "enabled": true
}
```

- `pointUid`：点位稳定标识，使用字符串保存，避免无符号整数兼容问题。
- `pointName`：便于操作员识别的点位名称，不作为唯一关联键。
- `deviceId`：资源管理中的 CNC 设备编号。
- `relationType`：服务位、等待位或安全交接位。
- `serviceActions`：该点位允许执行的 CNC 上料、下料等动作。
- `approachYaw`：AMR 服务 CNC 时的最终朝向，默认可继承点位 `yaw`。
- `enabled`：是否启用该映射。

## 编辑器交互

地图编辑器选中点位后，在属性面板提供“关联设备”区域：选择 CNC、关系类型、服务动作和到达朝向。资源管理中的 CNC 详情反向展示已绑定点位，避免在两个页面分别维护两份关系。

属性面板按使用频率分组：默认展开“基本信息”“位置与朝向”“关联 CNC”，折叠“通行与能力”“系统信息”。名称和别名可编辑，UID 与所属地图只读；朝向用角度编辑、内部仍保存弧度。禁用状态放在点位摘要旁，便于现场人员快速识别。

地图编辑器不设置底部状态栏，画布延伸至窗口底部；保存状态与地图校验结果统一由顶部操作区反馈。

一个 CNC 可以对应多个点位，例如上料位、下料位和等待位；一个服务点位默认只绑定一个 CNC。若现场确实存在共享交接位，再显式允许一对多并设置任务互斥。

运行时流程为：CNC 上报请求 → 系统通过 `deviceId` 找到服务点位 → 调度 AMR 到达该点位 → 按 `serviceActions` 执行交接。CNC 的在线状态、加工状态和握手信号仍由设备接入层维护。
