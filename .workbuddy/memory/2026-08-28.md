### 4. 限速区速度设置 + 管制区覆盖视觉反馈
- 文件：`src/types/domain.ts`、`src/views/MapEditorView.vue`、`src/styles/main.css`

**类型变更**
- `MapControlZone` 新增可选字段 `speedLimit?: number`

**限速设置**
- 新增 `zoneSpeedLimit` ref（默认 0.5 m/s），绘制面板中选「限速区」时显示限速值输入
- 创建管制区时若为限速区则写入 `speedLimit`
- 属性面板新增 `isSpeedZone` computed（判断 `type.includes('限速')`），限速区才显示限速值输入
- 属性面板提示文案动态拼接当前限速值

**覆盖检测（几何计算）**
- `isPointInZone(x,y,zone)`：点在矩形内
- `segmentIntersectsZone(x1,y1,x2,y2,zone)`：线段与矩形相交（端点在内 或 参数化裁剪区间有交集，实现「部分覆盖也算」）
- `zoneCoverage` computed：一次性算出所有被覆盖的 point/route id 集合并缓存，避免每次渲染做 O(n×m) 计算
- `isCovered(kind,id)`：供模板查询

**视觉反馈**
- 模板给路线/点位加 `covered` class
- CSS 用 `.covered:not(.selected)` 让被覆盖对象透明度降到 35%（不动颜色/线型），选中态优先不被覆盖
