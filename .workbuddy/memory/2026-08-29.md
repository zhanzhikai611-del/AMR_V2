## UI 设计规范审查（Web A11y / 响应式 / 对比度）
对 AMR_v2 前端做了 Web 界面设计规范审查，结论已写入 `UI设计规范审查报告.md`。关键发现：
- **P0 响应式**：`main.css:46` 的 `html,body,#app{min-width:1180px}` 阻断小屏，现有多档 @media 断点被架空。
- **P1 对比度**：`--ink-500 #8192a1`(≈3.2:1)、`--ink-400 #9aa8b5`(≈2.4:1) 低于 WCAG AA 4.5:1，用于大量副文本/表头。
- **P2 表格**：所有 `<th>` 缺 `scope="col"`，无 `<caption>`。
- **P2 对话框**：有 `aria-modal` 但缺焦点陷阱与 Esc 关闭。
- **P2 变量**：`--ink-300/--ink-600` 被引用但未在 `:root` 定义。
- 亮点：语义地标、装饰图标 `aria-hidden`、图标按钮 `aria-label`、地图标记键盘可达、`:focus-visible`、`prefers-reduced-motion` 均到位。
- 用户尚未要求修复，仅审查。
